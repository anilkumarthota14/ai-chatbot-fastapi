# AI Chatbot using FastAPI and Groq API

## Overview
This project is a backend AI chatbot built using Python, FastAPI, and Groq API integration.

## Features
- AI chatbot API
- FastAPI backend
- REST API endpoints
- Swagger UI testing
- Secure API key handling
- Git & GitHub integration

## Technologies Used
- Python
- FastAPI
- Groq API
- Uvicorn
- Git
- GitHub

## Run Locally

```bash
uvicorn app.main:app --reload
```
